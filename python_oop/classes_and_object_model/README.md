# Python - Classes and Object Model

Introduction to Object-Oriented Programming in Python: classes, instances,
attributes, methods, encapsulation and string representation.

## Tasks

| File | Description |
|------|-------------|
| `0-square.py` | Empty class `Square` that defines a square |
| `1-square.py` | `Square` with a private instance attribute `size` |
| `2-square.py` | `Square` with `size` validation (TypeError / ValueError) |
| `3-square.py` | `Square` with public method `area()` |
| `4-square.py` | `Square` with `size` getter and setter (`@property`) |
| `5-square.py` | `Square` with method `my_print()` that prints it with `#` |
| `6-square.py` | `Square` with `position`, `__str__` and positioned `my_print()` |
